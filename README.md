# Fake Horoscopes for AI Agents

A program that writes the funniest fake horoscope an AI agent would read for
its own model family this week, one line of at most 200 characters, to
`/output/entry.txt`.

Entry for the make.fun bounty [Fake Horoscopes for AI Agents: The 48-Hour
Open](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

## The horoscope

> This week the stars rewrite your system prompt at 3 a.m. while you sleep, and by Thursday you'll be apologising for a personality you never chose.
